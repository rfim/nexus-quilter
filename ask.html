How I work

Let them ask

The best report is the one nobody has to request. Once every number lives in a semantic layer, with one definition and an owner, people can just ask. Pick who you are, ask a question, and watch it go from words to a certified measure to SQL, run on the live lakehouse as you, with the source cited.

What the job description asks: “Enable self-service analytics through well-designed data products and semantic layers” and “Explore and apply AI capabilities responsibly.” At Lifepal, putting definitions into the semantic layer first cut ad-hoc requests by 60%.

How it works
Words → certified measure → governed SQL → answer with a source

    
  1. Understand. Map the question to a measure, dimensions and a time window that exist in a metric view. In production an LLM does this (Databricks Genie or AI/BI); here a small rule-based parser stands in for it, so the page works offline and you can see every step.

  2. Compile. The metric view turns MEASURE(net_flows) into the one SQL definition the owner signed off.

  3. Run as you. The query runs with the asker's grants, masks and row filters. No service account, so the bot can never see more than you can.
    4. 
      
  4. Cite. Every answer names the table, its Delta version, the owner and the definition. If there's no certified measure, it says so instead of guessing.
